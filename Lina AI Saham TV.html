⚙️ Pengaturan

Daftar gratis di financialmodelingprep.com (250 request/hari gratis). FMP support CORS langsung - super cepat untuk US stocks (AAPL, TSLA, NVDA, dll).

Optional. Yahoo Finance (untuk IDX/Crypto) butuh CORS proxy karena CORS policy. Public proxy gratis (allorigins, codetabs) sering down/rate-limited. Deploy Cloudflare Worker sendiri - lihat panduan di README. Format URL: https://[worker-url]/?url= (akan ditambah URL target setelahnya).

💡 Tips Performa:

  • US stocks: Pakai FMP API (langsung, tanpa proxy, super cepat ~500ms)
  • IDX/Crypto: Butuh CORS proxy untuk Yahoo Finance (FMP tidak support free)
  • Berita: Yahoo Finance search (perlu CORS proxy untuk IDX/Crypto)
  • Teknikal: 1 tahun historical data cukup untuk EMA 200, RSI, MACD, BB
