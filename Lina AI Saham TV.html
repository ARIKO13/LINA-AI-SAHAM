⚙️ Pengaturan

Daftar gratis di financialmodelingprep.com (250 request/hari gratis). FMP support CORS langsung - super cepat untuk US stocks (AAPL, TSLA, NVDA, dll).

Daftar gratis di twelvedata.com/pricing (800 request/hari gratis). Twelve Data CORS-friendly langsung - support saham IDX (BBCA, BBRI, TLKM, dll) dan crypto. Tanpa ini, IDX butuh CORS proxy (Yahoo Finance).

Optional. Hanya dipakai kalau Binance (crypto) / FMP (US) / Twelve Data (IDX) semua gagal. Deploy Cloudflare Worker - lihat panduan di README.

🚀 Routing Data (NO Yahoo Finance kalau ada API keys):

  • Crypto (BTCUSD, ETHUSD, dll): Binance API - instant, no key, CORS-friendly
  • US stocks (AAPL, TSLA, NVDA): FMP API - super cepat, butuh API key
  • IDX (BBCA, BBRI, TLKM): Twelve Data - CORS-friendly, butuh API key
  • Fallback: Cloudflare Worker → Yahoo Finance (kalau semua di atas gagal)
